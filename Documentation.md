# Documentation of dart files

## 1. juicy_button.dart
Bouncy effect upon the buttons/icons. Import this file and nest this to a button to have the button expand slightly when mouse is nearby, then bounce when the button is pressed (mouse is clicked).

## 2. glass_container.dart
"Frosted-glass" like UI on wherever you nest this widget on. It can be nested on a button, an icon, or even the whole page. Make sure something colourful is sitting behind this widget.

## 3. adaptive_layout.dart
This file decides to run which layout based on the screen pixels. For example, if you have different layout when your app is running on desktop and mobile phone, import this file to switch between them.

## 4. spaced_flex.dart
Provides constant spacing between elements than are in a column or in a row. You only need to set the constant spacing between elements once.
